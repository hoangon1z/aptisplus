# Backend authentication

Run `docker compose up -d --build`, then open https://localhost:3443. Local Caddy uses its internal CA: trust that development CA in the browser. Production requires a real hostname/certificate and matching APP_ORIGIN. Secrets are generated in untracked .env; never commit them. PostgreSQL has a persistent volume and no published port. Only the proxy is published on loopback; app trusts X-Real-IP ONLY because Caddy overwrites it and app has no public port.

Endpoints: POST /api/auth/register, login, logout, profile; GET /api/auth/me. JWT is HS256 with issuer/audience/expiry and server-side revocable session lookup. No JWT in localStorage. Seven-day session, HttpOnly/Secure/SameSite=Lax host cookie. Passwords12–128 characters, scrypt salted hashes, parameterized SQL. Atomic PostgreSQL counters limit each IP/email to20 auth attempts/15min. Exact Origin required for writes. IP/email tracking uses keyed HMAC; no passwords/tokens logged. Session contains user agent. New accounts always student; admin layout denies non-admin server-side. Schema initializes only on a NEW database volume; future schema changes require migrations, never delete a live volume to upgrade.

Scope: authentication/account backend only. Exam bank, drafts, answers, audio, plans and grading still require separate database/API migration. Existing educational sample tests remain explicitly sample content, not claimed as official exams. No email verification, password recovery, password change, MFA, refresh-token rotation or production deployment claimed. Sessions expire after7 days and are revoked at logout. Implement cleanup/retention of expired sessions and auth events before public production; establish backup/restore and monitoring. HTTPS proxy is local development, not an internet deployment.

Development frontend http://localhost:3000 uses APP_ORIGIN and DATABASE_URL in untracked .env. PostgreSQL development port is bound only to127.0.0.1:55432. Container app overrides both origin and database URL for proxy networking. Remove DB port mapping for public production. Account/login mock removed; educational local data migration remains pending. Smoke script scripts/auth-smoke.mjs creates synthetic test account records, never real user data.

Auth feedback: explicit pending/success/error states, spinner with reduced-motion fallback, one-second success acknowledgement before replace navigation, protected workspace loading boundary. scripts/auth-feedback.mjs verifies pending button disable, success alert, redirect and wrong-password recovery on the real development API.
